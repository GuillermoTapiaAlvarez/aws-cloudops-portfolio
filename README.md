# AWS CloudOps Portfolio

Hands-on AWS cloud infrastructure portfolio focused on building practical skills in:

- AWS networking
- Linux administration
- Infrastructure as Code with Terraform
- Git and GitHub
- Monitoring and troubleshooting
- Cloud security
- Automation

## Project Goal

This repository will grow into a production-style AWS environment built incrementally.

The first phase focuses on designing and deploying a VPC with:

- Public and private subnets
- Internet Gateway
- Route tables
- Security groups
- Amazon EC2
- Linux
- Nginx

The infrastructure will first be built manually to understand the underlying AWS components, then recreated using Terraform.
